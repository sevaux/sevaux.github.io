Procedure pour se connecter depuis l'extérieur

- dans une fenetre (a laisser ouverte) :
ssh -L 2222:bof.univ-ubs.fr:22 sevaux@transit.univ-ubs.fr

- dans une autre fenetre :
ssh -p 2222 -CX localhost puis
ssh petitsevaux@ens-dsiva-0020.ens.univ-ubs.fr

ou en une seule fois (a verifier) :
ssh -J localhost:2222 petitsevaux@ens-dsiva-0020.ens.univ-ubs.fr
